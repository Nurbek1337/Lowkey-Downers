LOWKEY DOWNERS — PATCH ДЛЯ 8 ИГРОВЫХ ПЕРСОНАЖЕЙ

Установка в ИСХОДНЫЙ проект:
1. Сделай копию проекта или хотя бы папки Assets.
2. Распакуй содержимое архива в корень проекта с заменой файлов.
3. Открой проект в Unity и дождись окончания компиляции.
4. Открой сцену Assets/Scenes/BossArena2.unity.
5. В верхнем меню Unity выбери: Lowkey Downers -> Repair and Setup 8 Playable Characters.
6. Подтверди установку, затем сохрани сцену Cmd+S.
7. Нажми Play. Появится меню выбора ровно трёх героев из восьми.

ВАЖНО:
- Установщик ищет игрового персонажа только по точному имени BossPlayer2.
- Объект Boss больше не принимается за игрока; его тег исправляется на Untagged.
- Старые объекты Party_Gegwer, Party_Smirqc и CharacterRoster_* удаляются при повторной установке.
- Другие объекты арены и скрипты боссов установщик не удаляет.
- В проекте сейчас есть визуальные ассеты Ney, но нет отдельных спрайтов для остальных семи героев. Поэтому остальные пока используют спрайт Ney с разными оттенками. Это временные визуальные заглушки, не финальный арт.
- После выбора: 1/2/3 переключают активного героя, WASD/стрельба/Shift управляют им, Q использует способность (Ney использует Parry по существующей логике). Два других героя помогают автоматически.

Если Unity покажет ошибки компиляции, не запускай установщик повторно: пришли полный текст Console.
